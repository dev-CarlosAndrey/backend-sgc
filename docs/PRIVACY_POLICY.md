# Política de Privacidade — SGC (Sistema de Gerenciamento e Controle)

Este é um projeto acadêmico (Trabalho de Conclusão de Curso) desenvolvido para fins educacionais.

## Dados coletados
O sistema coleta dados de contato (nome, telefone/WhatsApp, e-mail) de usuários cadastrados internamente pela organização que utiliza o sistema, exclusivamente para fins de notificação sobre ordens de serviço e status de ativos.

## Uso dos dados
Os dados são utilizados apenas para envio de notificações operacionais via WhatsApp e e-mail, relacionadas ao uso do sistema.

## Compartilhamento
Os dados não são compartilhados com terceiros, exceto os provedores de infraestrutura necessários para o funcionamento do sistema (Meta/WhatsApp Business Platform, SendGrid).
